# ☕ Sip & Bloom – Café Website

A stylish and responsive café website built using **HTML, CSS, and JavaScript**. Sip & Bloom showcases a cozy café experience with a homepage, menu, and about page.

## 🌿 About the Project

Sip & Bloom is a beginner-friendly web development project designed to practice building a multi-page website with a warm, modern café theme.

The website includes café information, coffee menu items, images, and interactive order buttons.

## ✨ Features

- 🏠 **Home Page** – Welcoming hero section with coffee imagery.
- ☕ **Menu Page** – Displays coffee items and their prices.
- 📖 **About Page** – Introduces the café and its story.
- 📱 **Responsive Design** – CSS styling for desktop and mobile screens.
- 🎨 **Warm Design** – Cream and brown color palette.
- 🖱️ **Interactive Buttons** – JavaScript-powered order button alerts.
- ♿ **Keyboard Focus Styles** – Visible focus indicators for links and buttons.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
